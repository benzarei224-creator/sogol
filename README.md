# سوگل 🌸 — تقویم مدیریت زندگی شخصی

وب‌اپ (PWA) آفلاین برای آیفون و اندروید: تقویم شمسی با تعطیلات رسمی، چک‌لیست عادت‌ها، اهداف ۱۲ ماهه، مدیریت مالی به تومان، یادداشت و حال‌وهوای روزانه، کتابخانه، منوی هفتگی و دفترچه ایده.

**آدرس اپ:** https://benzarei224-creator.github.io/sogol/

## نصب روی آیفون
1. آدرس بالا را در **Safari** باز کنید.
2. دکمه‌ی اشتراک‌گذاری ← **Add to Home Screen**.
3. اپ را از آیکون «سوگل» باز کنید و فایل برنامه‌ی شخصی را از «انتخاب فایل» وارد کنید.

## حریم خصوصی
- هیچ اطلاعات شخصی در این مخزن نیست. برنامه‌ی شخصی (مناسبت‌ها و اهداف) یک فایل جداست که فقط داخل گوشی وارد می‌شود.
- همه‌ی داده‌ها فقط روی همان گوشی ذخیره می‌شود (localStorage و IndexedDB). از بخش «پشتیبان و تنظیمات» مرتب فایل پشتیبان بگیرید.

## ساختار
| مسیر | کاربرد |
|---|---|
| `index.html` | پوسته‌ی اپ |
| `app.css` | ظاهر، چیدمان موبایل/دسکتاپ و نسخه‌ی چاپی |
| `jalali.js` | تبدیل تاریخ شمسی |
| `holidays.js` | تعطیلات رسمی ۱۴۰۴ تا ۱۴۱۲ |
| `data.js` | پیش‌فرض‌ها (عادت‌ها، دسته‌های هزینه، جمله‌ها) |
| `app.js` | منطق و صفحه‌های اپ |
| `sw.js` | کار آفلاین؛ با هر به‌روزرسانی `VERSION` را عوض کنید |
